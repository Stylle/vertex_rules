# Vertex Rules

用于 Vertex 的可复用规则与脚本。导入前先阅读脚本，核对适用条件，并在测试任务上验证；删除类规则可能造成不可恢复的数据丢失。

## 使用

仓库中的文本文件提供规则示例，不是完整站点配置，也不需要单独部署 Docker 容器。请在 Vertex 的对应规则或脚本编辑器中按需使用，并根据当前版本的接口调整。

## 数据与隐私

只提交通用规则，不提交客户端连接信息、站点账号、RSS 私有链接、Cookie、密码、数据库或整站备份。示例统一使用占位符。

此前提交的运行备份已从当前版本移除。**历史提交、既有克隆及缓存仍可能保留旧副本；删除文件不能使已暴露的凭据失效。**曾使用其中配置的部署应更换相关密码、Token、Cookie 和私有订阅链接，并检查访问记录。
